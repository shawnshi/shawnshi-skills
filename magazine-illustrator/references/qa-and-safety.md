# 图像质检、事实与失败处理

在每张图片交付前读取。涉及医疗内容、患者信息、嵌入文字、真实人物、品牌标识或工具失败时，执行相应专项规则。

## 生成前检查

- 用户规格、渠道预设和任务对象是否一致；
- 图片数量、比例、风格、文字策略和禁止项是否明确；
- 是否包含真实患者身份、病历、检查报告、屏幕截图或其他敏感信息；
- 医疗、新闻、人物或机构事实是否有用户材料或可靠来源支持；
- 精确解剖、器械位置、操作步骤、剂量或诊断表现是否超出概念插画能力；
- 是否错误承诺具体像素、DPI、CMYK或印刷成品能力。

## 生成后视觉质检

逐张检查实际图片：

1. 恰好一张独立图片，不是长图、拼图、联系表或多页面版式；
2. 比例和渠道构图正确，主体、关键物件和安全区没有被裁断；
3. 准确表达对应文章观点，没有产生相反或误导性含义；
4. 人物、手部、面部、器械和空间关系没有明显异常；
5. 没有未要求的文字、Logo、水印、数字、伪造界面或无意义字符；
6. 文字安全区符合后期排版要求；
7. 系列图片的媒介、色板、母题和人物特征一致，同时具有必要的构图变化；
8. 用户禁用项、事实锁定、隐私和品牌要求全部满足。

## 医疗内容

### 概念表达

医疗AI、管理流程、医患沟通、数据治理等抽象主题可以使用概念插画，但必须：

- 使用虚构且不可识别的人物；
- 将屏幕和病历处理为抽象信息块，不生成姓名、证件号、病案号或检查结果；
- 不暗示AI已经作出诊断、治疗决定或保证临床结局；
- 避免明显不合理的医疗设备、穿戴方式和操作姿势。

### 事实型临床表达

解剖结构、手术步骤、器械位置、疾病体征、药物剂量或临床教学内容必须：

- 根据用户材料或可靠一手来源建立事实锁定；
- 不自行补全无法核实的细节；
- 缺少可靠依据时改为概念示意，或建议使用精确技术图、流程图或专业医学插图；
- 不把生成图作为唯一临床指导、诊断依据或患者决策依据。

## 人物、品牌与版权

- 不将虚构人物表述为真实当事人，不把插画伪装成新闻现场照片。
- 未经用户提供或授权，不复制商标、包装、出版物版式、水印或受保护角色。
- 用户要求参考某作品或出版物时，提取媒介、构图、色彩和编辑语气等一般特征，不复刻具体画面。
- 涉及真实人物时，遵守用户指定的身份和形象边界，不凭空补充敏感属性或经历。

## 中文及重要文字

- 无明确要求时不在画面中生成文字。
- 用户明确要求嵌入文字时逐字核对，不静默改写。
- 出现错字、漏字、重复字、乱码或额外文字时，只针对文字问题自动重试一次。
- 一次重试后仍不准确，交付无文字底图，并提供完整准确的叠加文字、建议位置、对齐方式和安全区。
- 不把错误文字图片标记为已通过。

## 失败处理

| 情况 | 处理 |
|---|---|
| 临时超时、空结果或可恢复错误 | 使用更短、更明确的提示自动重试一次 |
| 比例、构图、文字或明显视觉缺陷 | 只修正失败项并重试一次，保留其他约束 |
| 工具不存在或当前不可用 | 不虚构工具、不声称已生成；进入提示词降级 |
| 内容安全拒绝 | 不绕过限制；安全改写仍不成立时说明不能生成 |
| 系列中的单张失败 | 保留已通过图片，仅将失败图片标为受阻 |
| 第二次仍失败 | 停止自动重试，提供降级交付 |

## 提示词降级包

明确写明“图片未生成”，并交付：

- 图片编号和用途；
- 目标渠道、比例和安全区；
- 可直接用于图像工具的最终提示词；
- 必须包含和禁止出现的元素；
- 准确的文字叠加内容及位置；
- 医疗或事实限制；
- 系列任务中已完成、失败和待生成图片的状态。

不得把提示词、占位符、文字描述或失败调用包装成已完成图片。
