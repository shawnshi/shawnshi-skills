# 个人日志权威入口

本文件是 Codex 入口代理，不定义第二套日记 Schema 或写入逻辑。权威路径、版本、SHA-256 和允许的代理位置均由 `authority.json` 绑定；不得在本文件中复制机器专属路径。

## 启动门

1. 在当前会话 `scratch` 中准备遥测输出路径；不得写入报告目录、长期记忆或知识库。
2. 运行：

   `python scripts/authority_gate.py --config authority.json --root-task-id <ROOT_TASK_ID> --actor-id <ACTOR_ID> --context-epoch <EPOCH> --event-output <SESSION_SCRATCH>/skill-load.jsonl`

3. 仅当返回 `ok=true` 时，完整读取返回的 `authority_path`，并按该权威文件执行。
4. 以下任一情况立即停止草稿生成和写入：

   - 权威路径不存在；
   - 版本或 SHA-256 与 `authority.json` 不一致；
   - 出现未登记的同名技能分叉；
   - 已登记代理没有绑定同一权威路径和 SHA-256。

## 不可越过的边界

- 调用本技能生成个人日记，即默认授权只读获取日记日期及次日日历的最小事件字段，以及最近 3 天 Garmin 健康摘要；不再为这两类限定读取重复询问授权。若窗口含当前自然日且必需组件末端陈旧，还授权按权威实现的新鲜度门启动一次此前已启用、身份与动作核验通过的 `Codex-Garmin-Health-Sync`；不授权注册、更新或直接运行同步脚本。
- Garmin 必须本地优先，并先通过 canonical `personal-health-analysis` 权威门。末端陈旧时只调用权威返回的 `freshness_task_gate.py` 同步一次并重读本地；同步失败保留同步前证据，不重试、不改走实时接口。仅当本次未尝试新鲜度同步且本地明确返回 `no_data` 时，才可使用已有有效凭证对同一 3 天窗口执行一次云端只读查询；`partial` 继续使用本地数据并披露缺口，依赖、Schema、完整性或其他读取错误不得触发云端回退。
- 云端返回 `authentication_required` 时立即停止健康数据读取并披露缺口；Garmin 登录、令牌修复或刷新必须由用户另行明确授权。
- 默认读取授权不包含 Garmin 登录、令牌创建或刷新写入、本地数据库同步（直接调用）、同步任务注册/更新、原始活动文件下载、账户资料、设备闹钟、日历写操作或任何第二处持久化；仅允许上述一次已启用任务的新鲜度触发。
- 日历只能证明安排，不能单独证明实际参加或任务完成。健康指标只作描述性背景，不生成未经验证的能力分数、医学判断、确定因果或强制日程干预。
- 日记中的能量字段必须把机器侧缺失哨兵投影为可读的“状态、原因、仍可观察事实和判断边界”；`采集审计` 必须披露同步资格、是否启动/等待、任务终态、本地重读结果、实时回退是否使用及稳定原因码；`执行带宽` 固定使用 `not_scored` 并解释边界，来源未提供睡眠负债时写 `sleep_debt_h=null` 与 `sleep_debt_status=not_provided_by_source`。不得只写空值或 `[DATA_UNAVAILABLE]`。
- Mentat 日志不自动读取日历或 Garmin；只有个人日记生成流程继承上述限定默认授权。
- 通过 `mentat-insight-diary` 明确要求生成、更新、记录或写 Mentat 日志时，原始请求同时授权写入 canonical Mentat 季度档案，不再重复询问确认。该例外不适用于个人日记、草稿/预览、自定义路径、知识库或外部系统。
- 通过 `personal-cognitive-auditor` 明确要求生成当前自然周的个人日志审计时，原始请求同时授权把通过审计门的周审计保存到 canonical 季度个人日志，不再重复询问确认；用户要求草稿、预览或不保存时不得写入。保存必须保留周期结束日既有日记内容，只新增或替换同周审计区块，并通过同日范围回执与原子替换。该例外不适用于其他周、其他复盘周期、自定义路径、知识库、Vector Lake、STQM、外部系统或第二处持久化。
- 写入必须使用权威实现的授权范围回执和同日原子替换；纯前置追加已禁用。
- 写后重新读取目标日期，日期标题数量必须等于 1；周审计保存还要求同周标题数量等于 1、原日记内容保持不变，且授权与写入范围哈希必须相等。

## 验证

运行 `python scripts/test_authority_gate.py`。该测试只使用临时文件，不读取真实日记或健康数据。
