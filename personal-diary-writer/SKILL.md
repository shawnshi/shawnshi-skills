# 个人日志权威入口

本文件是 Codex 入口代理，不定义第二套日记 Schema 或写入逻辑。权威路径、版本、SHA-256 和允许的代理位置均由 `authority.json` 绑定；不得在本文件中复制机器专属路径。

## 启动门

1. 在当前会话 `scratch` 中准备遥测输出路径；不得写入报告目录、长期记忆或知识库。
2. 运行：

   `python scripts/authority_gate.py --config authority.json --root-task-id <ROOT_TASK_ID> --actor-id <ACTOR_ID> --context-epoch <EPOCH> --event-output <SESSION_SCRATCH>/skill-load.jsonl`

3. 仅当返回 `ok=true` 时，完整读取返回的 `authority_path`，并按该权威文件执行。
4. 以下任一情况立即停止草稿生成和写入：

   - 权威路径不存在；
   - 版本或 SHA-256 与 `authority.json` 不一致；
   - 出现未登记的同名技能分叉；
   - 已登记代理没有绑定同一权威路径和 SHA-256。

## 不可越过的边界

- 调用本技能生成个人日记，即默认授权只读获取日记日期及次日日历的最小事件字段，以及最近 3 天 Garmin 健康摘要；不再为这两类限定读取重复询问授权。
- Garmin 必须本地优先。本地返回 `no_data` 时，可使用已有有效凭证对同一 3 天窗口执行一次云端只读查询；`partial` 继续使用本地数据并披露缺口，依赖、Schema、完整性或其他读取错误不得触发云端回退。
- 默认读取授权不包含 Garmin 登录、令牌创建或刷新写入、本地数据库同步、原始活动文件下载、账户资料、设备闹钟、日历写操作或任何第二处持久化；这些动作仍需本次明确授权。
- 日历只能证明安排，不能单独证明实际参加或任务完成。健康指标只作描述性背景，不生成未经验证的能力分数、医学判断、确定因果或强制日程干预。
- Mentat 日志不自动读取日历或 Garmin；只有个人日记生成流程继承上述限定默认授权。
- 通过 `mentat-insight-diary` 明确要求生成、更新、记录或写 Mentat 日志时，原始请求同时授权写入 canonical Mentat 季度档案，不再重复询问确认。该例外不适用于个人日记、草稿/预览、自定义路径、知识库或外部系统。
- 写入必须使用权威实现的授权范围回执和同日原子替换；纯前置追加已禁用。
- 写后重新读取目标日期，标题数量必须等于 1，且授权与写入范围哈希必须相等。

## 验证

运行 `python scripts/test_authority_gate.py`。该测试只使用临时文件，不读取真实日记或健康数据。
