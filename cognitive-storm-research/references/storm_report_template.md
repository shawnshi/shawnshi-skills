# STORM 综合研究报告模板

标准和深度研究使用本模板。保留各部分的核心语义，但可根据受众、语言和证据量调整标题、发现数量和视角数量。没有证据支持的内容标明“未发现”或“不适用”，不得为了填满模板而编造。仅在用户明确要求保存 Markdown 文件时添加所需的 frontmatter。

结构：决策摘要 → 方法与范围 → 关键发现 → 证据与矛盾 → 相关视角 → 选项与建议 → 未知项 → 自检/独立审查与整改 → 来源索引。

```markdown
# [研究主题]

> **研究状态**：[完整 / 部分 / 受阻]
>
> **研究档位**：[标准 / 深度]
>
> **资料截止时间**：[YYYY-MM-DD HH:mm，时区]
>
> **决策问题**：[本报告要支持的具体决策]

## 1. 决策摘要

- **核心结论**：[直接回答决策问题]
- **建议及强度**：[强 / 中 / 弱 / 暂不建议行动]
- **关键依据**：[最重要的2–4项证据，附相邻引用]
- **主要不确定性**：[最可能改变结论的未知项]
- **改变结论的条件**：[证伪条件或关键新证据]

## 2. 研究方法与范围

- **受众与用途**：...
- **地区、时间与关键定义**：...
- **纳入与排除范围**：...
- **来源限制与检索方法**：...
- **共享预算**：[来源/轮次/截止时间/可计量工具额度；已用、余量及审查预留]
- **支持与反证覆盖**：[关键Claim ID；已核验方向、待查来源与未覆盖域，不以状态填齐代替覆盖]
- **停止原因**：[覆盖完成 / 整体饱和 / 预算退出；对应证据或耗尽项]
- **完成状态及限制**：[无论停止原因，决策关键缺口如何影响状态及建议强度]

## 3. 关键发现

### [发现标题；按重要性排序，数量由证据决定]

- **类型**：[事实 / 解释 / 预测]
- **结论**：...
- **置信度**：[高 / 中 / 低]，理由：...
- **支持证据**：[S1：来源标题](URL)；[S2：来源标题](URL)
- **反证或限制**：...
- **决策含义**：...

[按实际发现数量重复]

## 4. 证据与矛盾图

### 已确认事实

| Claim ID | 事实 | 独立证据链 | 适用口径 |
|---|---|---|---|
| C01 | ... | L1(S1,S2)、L2(S3) | ... |

`C*` 为主张、`S*` 为来源、`L*` 为上游证据链。示例中 S1 原报告与 S2 转载共用 L1，仅 S3 的独立采集形成 L2；没有 S3 时只有一条链，不能凭两篇材料确认需交叉验证的主张。权威唯一来源例外须说明适用依据。

### 有争议或未解决主张

| Claim ID | 主张 | 支持证据 | 反对证据 | 冲突原因 | 状态及处理 |
|---|---|---|---|---|---|
| C02 | ... | S3 | S4 | 定义/时间/范围/方法/利益 | contested/unconfirmed；如何影响建议 |

- **少数意见**：...
- **尚未被充分覆盖的变量**：...

- **核心判断**：...
- **对应主张与来源**：C01、C02；S1、S3
- **反证或边界**：...
- **对决策的独特贡献**：...

## 6. 决策选项与建议

| 选项 | 支持证据 | 主要风险/反证 | 可逆性 | 建议强度 |
|---|---|---|---|---|
| A | ... | ... | 高/中/低 | 强/中/弱 |

- **推荐方案**：...
- **最小下一步**：...

- **证伪条件**：出现哪些证据或结果时应暂停、调整或推翻建议。

## 7. 未知项与后续研究

| 未知项 | 对结论的影响 | 所需证据 | 优先级 |
|---|---|---|---|

## 8. 自检/独立审查、整改与质量状态

- **必要独立审查及触发依据**：[是/否；用户要求或当前治理门]
- **实际审查方式**：[轻量自检 / 独立审查 / 按当前合同收到的真实用户批准 / 必要审查受阻；自检不是独立红队]
- **审查者是否参与原稿生成**：[是/否/不适用；据实填写]
- **真实回执或批准定位**：[材料定位；未取得写明缺失，不编造]
- **整改后复核结果**：[问题、对应Claim ID、复核者与证据；未复核不得放行]
- **最弱证据链**：...
- **偏差与覆盖缺口**：...
- **发现的问题及整改**：[补证 / 删除 / 降级 / 保留争议]
- **仍未解决的问题**：...
- **最终状态**：[完整 / 部分 / 受阻]，理由：...

## 9. 来源索引

| Source ID | 来源与发布者 | 来源类型 | 发布日/事件日/访问日 | 适用范围 | 独立证据链 | 支持的Claim ID |
|---|---|---|---|---|---|---|
| S1 | [原报告](URL) | 原始数据 | ... | ... | L1 | C01 |
| S2 | [S1转载](URL) | 二手 | ... | ... | L1 | C01 |
| S3 | [独立采集](URL) | 原始数据 | ... | ... | L2 | C01 |
```

公开来源必须保留可点击链接；用户提供材料使用“文件名＋页码/章节/表图”定位。来源索引不能替代关键主张旁的相邻引用。
