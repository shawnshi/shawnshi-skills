# 并发 ID 映射与上下文续接

进入对应分支前，按入口要求必读本文件；单代理且无交接/压缩续接时不加载。共享账本、预算、失败状态与必要独立审查仍遵循主入口，不新增持久化授权。

## 并发分支 ID 映射（派发前及合并前）

分支局部 ID 带前缀（如 A:C01、B:C01、A:S1、B:L1），由主代理按主张内容与上游来源统一映射为全局 C/S/L ID，并同步更新全部引用；同号不等于同一主张，不同来源 ID 也不证明链独立。

## 跨分支交接与压缩续接（执行前）

跨分支或压缩上下文时使用紧凑交接：`范围/截止时间 | 主张ID及状态 | S→L上游链与材料定位 | 冲突/未覆盖域 | 已用/余量（含审查预留） | 下一步及停止原因`。示例：`A:C01→C01；B:C01→C02；A:S1/B:S1→S1→L1；B partial，C02反证未查；总工具剩2次（审查预留1次）；下一步核验C02反证`。交接保留映射和失败域，不复制整篇原文、不另造完整分支报告；沿用一个主交付，账本与交接可仅在当前对话维护，不自动落盘。
