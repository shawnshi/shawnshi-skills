# Verified domain references

This directory contains only domain files promoted by
`scripts/domain_manager.py promote`.

An active domain must:

- use the canonical `verified/<name>.md` path;
- include explicit source and structural primitives;
- complete every mechanism field;
- match the SHA-256 and source recorded in
  `references/verified_domains.json`.

This README is descriptive and is not itself an active domain.
