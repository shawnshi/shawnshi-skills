# Advanced Modules

These are optional analytical lenses. A keyword match is only a discovery hint
and never triggers a module automatically.

| Module | Use when | Function |
|---|---|---|
| `yoneda_probe` | Important properties remain unobserved | Examine an object through evidenced relations |
| `natural_transformation` | Two explicit mappings must be compared over change | Test whether the transition preserves structure |
| `monad_risk` | Side effects materially affect the decision | Make legal, cost and trust effects explicit |
| `adjoint_balancer` | User wants an explicit feasibility trade-off | Compare capability and constraint |
| `kan_extension` | A verified local mechanism may transfer | Compare extension assumptions and distortion |

Numbers in module examples are variables unless backed by a cited source or
user data. Module selection and strategy choice remain human judgments.
