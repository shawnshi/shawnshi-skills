# 认知与执行复盘

## 最短用法：生成不等于保存

- `复盘今日日志，只读，不同步` 或 `本周个人日志审计，草稿`：按已有材料生成并披露缺口。用户要求草稿、预览、只读或不保存时，保持只读，不写 canonical，也不触发新鲜度同步。
- 周/月/季度仅受保护精确请求通过全部门禁才默认保存；不是所有“周结”或等价生成意图都授权保存。进入此分支先读 [受保护周期保存](references/periodic_save.md)，内容门通过不等于保存授权。

## 工作流程

1. 确认复盘周期、目标和可用材料。日/周/月/季/年分别使用 `prompts/DAILY.md`、`prompts/WEEKLY.md`、`prompts/MONTHLY.md`、`prompts/QUARTERLY.md`、`prompts/ANNUAL.md`；默认对应当日/本自然周/当月/本季度/当年窗口。日期、时区与周期起点优先采用用户指定值，否则使用会话可确认的本地日期与时区并披露；只读模式仍遵守原窗口。默认只读获取该周期内的日历事件与本地 Garmin 健康摘要，不再为这两类本地读取单独询问授权；用户明确要求“个人日志周审计”“本周个人日志审计”或等价任务时，还授权通过 `personal-diary-writer` 权威门只读提取该自然周的 canonical 个人日志日期块。联网读取和其他私人来源仍需用户在当前任务中明确授权。没有数据时列出缺口，不补造事实。
2. 日历只读取与周期相关的事件、时间和必要描述，不创建、修改、删除或回复事件；日程只能证明安排，不能单独证明出席或完成。
3. Garmin 采集前必须读取 [能量管理数据合同](references/energy_management.md) 的来源状态机与新鲜度门，并通过 canonical `personal-health-analysis` 权威门。仅窗口包含当前自然日且必需组件末端不新鲜时，本请求才授权一次两阶段受控同步；历史窗口及草稿、预览、只读、不同步、不联网请求不触发。失败不重试、不改实时来源，披露真实缺口；不得用其他技能默认读取扩大本任务授权。
4. 按“事实—解释—影响—下一步”分离信息。区分可控行为、外部约束和证据不足项，避免把复杂结果简化为人格判断。
5. 对照用户明确承诺，标记“完成、部分完成、未完成、无法判断”，并引用对应证据。
6. 按证据量识别值得报告的重复模式，说明证据强度和可能的替代解释。不要把推测写成结论，也不为满足固定数量补写模式。
7. 提出少量可执行动作；每个动作写明触发条件、完成标准和最小下一步。生成能量管理、健康背景或趋势判断前，必须读取 [能量管理数据合同](references/energy_management.md) 的字段投影和资格边界；不得据健康信号评分、决定训练或重要事项、推断认知/职业表现或确定因果。
8. 仅当材料规模大且可以独立拆分时使用子代理做交叉核对。不要让子代理接触超出任务所需的私人数据。
9. 个人周、月、季度审计通过内容门、周期拓扑门和受保护精确请求门后，默认自动保存到 canonical 季度个人日志；审计门、权威门、请求门、范围门和写后校验全部通过才算保存成功。保存前必须完整遵循 [受保护周期保存](references/periodic_save.md) 与对应模板；任何门失败停止保存，不直写或转存第二处。日度、年度、自定义路径及交接不自动保存，仍须另行明确授权。

## 资源

- 需要日、周、月、季度或年度模板时，读取 `prompts/` 下对应文件；模板继承日历与 Garmin 的默认只读授权，但不扩大到其他私人数据源。周、月、季度模板同时定义 canonical 自动保存封套，必须完整遵循。
- 出现 Garmin、能量管理、健康背景或趋势判断时，必须读取 `references/energy_management.md`；需要通用字段含义或交接格式时，再按需读取 `references/templates.md`、`references/semantic_layer.md` 或 `references/handoff_contract.md`。
- 组织复盘输出时按需读取 [输出与验证](references/templates.md) 的结构；生成文件草稿后必须读取其验证分层，运行 `python scripts/audit_gate.py <draft_file>`；来自模板时加 `--enforce-template-fields`。脚本不可用时人工检查仅支持草稿，不替代保存门。

## 边界

- 默认只读获取复盘周期内的日历与本地 Garmin 数据；只取完成当前复盘所需的最小字段和精确时间范围，不为满足趋势算法自动扩大窗口。
- 不自动读取历史对话、邮件或全局记忆；只有明确的个人日志周审计允许经权威门读取当前自然周的 canonical 日期块，不得扩展到其他周或其他私人目录。
- 默认授权不包含任意联网、日历写操作、Garmin 登录或令牌持久化、原始活动文件下载、注册或修改同步任务、直接运行同步脚本或任何第二处持久化。唯一例外是第 3 步的新鲜度门：可直接运行一次两阶段同步。`activities` 与 `training_load_series` 也不属于默认能量管理组件。
- 个人周、月、季度审计只在受保护结构化请求门通过后写入 canonical 季度个人日志；草稿、预览、只读、“不保存”或其他修饰请求不得写入。其他复盘、知识库、Vector Lake、外部系统或第二处持久化仍需单独明确授权。
- 不把日程安排当作实际出席证据，不把健康指标相关性写成医学诊断、人格定性、认知或工作能力判断、确定因果。
- 不输出隐藏推理过程；只呈现证据、判断和不确定性。
- 不因追求强硬语气而忽略客观原因、数据质量或安全风险。保持直接、克制和具体，不羞辱、辱骂或假装掌握用户动机；健康动作仅作一般生活建议，危险症状或持续异常建议联系合格医疗人员。
