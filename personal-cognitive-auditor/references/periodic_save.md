# 受保护周期保存

仅个人周、月、季度 canonical 保存分支读取本文件；普通生成不获得写入授权。

## 最短用法：生成不等于保存

- 只生成：`复盘今日日志，只读，不同步` 或 `本周个人日志审计，草稿`。按已有材料生成复盘并披露缺口。当用户要求草稿、预览、只读或不保存时，保持只读，不写入 canonical 目标，也不触发新鲜度同步。
- 生成并申请 canonical 保存：受保护用户事件中的精确 `本周个人日志审计`（月、季度仅使用下节既有精确请求）。不是所有“周结”“复盘”或等价生成意图都能通过保存门；不得把修饰请求改写成精确请求，也不扩大授权词或周期范围。
- 最短校验链：读取对应模板 → 生成临时草稿 → `python scripts/audit_gate.py <draft_file> --enforce-template-fields --period-type weekly --period-id <YYYY-Www>` → 经日记权威门生成 scope 与绑定的 `periodic-audit-request-v1` approval → 对应 `replace-weekly-audit` → 写后校验。月、季度使用其既有周期 ID 与动作。内容门通过不等于保存授权；不得直接写 canonical 或另存第二处。
- 缺少健康数据时可如实降级为事实与数据缺口，不补造数值或完成状态；模板模式仍须填写能量管理稳定字段及不可用原因，不能删节规避内容门。健康读取失败不授权绕过请求、权威、范围或保存门；脚本不可用时人工检查只支持草稿交付，不替代自动保存门。
- 周期写入保留结束日既有日记与其他周期区块，只替换目标同周期 H2；日记后续使用 `replace-personal-diary` 更新正文时也保留同日合法周/月/季区块。重复或非法周期区块失败关闭，不使用整日 `replace-date` 代替周期保存。

## 保存门与标题拓扑

个人周、月、季度审计通过 `audit_gate.py` 的内容门与周期标题拓扑门后，默认自动保存到 `personal-diary-writer` 返回的 canonical 季度个人日志。自动保存只接受受保护用户事件中的精确 canonical 请求：`本周个人日志审计`/`个人日志周审计`、`本月个人日志审计`/`个人日志月度审计`、`本季度个人日志审计`/`个人日志季度审计`，或包含周期 ID 的 `AUDIT_AUTOSAVE` 结构化命令；可带单一 `[OVERRIDE]` 或 `[WARROOM]` 前缀。任何额外修饰都不自动写入，因此草稿、预览、只读或不保存请求必然失败关闭。调用层必须生成 `periodic-audit-request-v1` artifact，绑定受保护用户事件 ID 与文本 SHA-256、周期、动作、canonical 目标、scope hash 和 `canonical_autosave` 策略。保存只新增或替换周期结束日中的同周期 H2 审计区块；payload 的第一个非空行且唯一 H2 必须是目标周期标题，其余标题只能为 H3 或更深；0–3 个空格缩进的 ATX H1/H2 与 Setext H1/H2 同样禁止。日期块不存在时只创建日期标题与该审计区块。任何审计门、权威门、请求门、范围门或写后校验失败都停止保存，不得直写文件或转存到第二处。日度、年度、自定义路径及交接仍须另行明确授权。
