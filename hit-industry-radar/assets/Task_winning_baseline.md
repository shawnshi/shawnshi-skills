# 指定厂商公开动态检索提示

目标实体：卫宁健康及用户明确指定的产品线。
时间范围：`[START_DATE]` 至 `[END_DATE]`，继承 SKILL.md 与 references/research_contract.md 的事件日期、时区、截止、预算、去重和保存合同，不独立归档。仅明确指定该厂商时启用，不代表默认立场。

## 检索面

1. 公司公告、定期报告和正式产品发布；
2. 政府采购、中标和公开项目资料；
3. 医疗机构或监管机构发布的直接材料。

## 建议返回结构

```markdown
### [模块名称]：[事件极简标题]
- **事件日期 / 网页发布日期**：[分别列出；财报用披露日，财务期间另列]
- **事件键 / 项目标段阶段**：[规范键；预算、中标额、合同额不相加]
- **检索覆盖**：[检索面、查询/来源及结果；complete/partial/blocked]
- **已核实事实**：[主体和动作；金额、版本未公开时写“未披露”]
- **来源**：[原始页面 URL、血缘、类型、访问状态]
- **证据限制**：[单一来源、口径或待核项]
```

仅覆盖完整且没有合格事件时返回“本周期未发现符合纳入标准的公开事件”；覆盖不足报 partial，无可用证据报 blocked。本文件只是检索提示，不是事实来源。
