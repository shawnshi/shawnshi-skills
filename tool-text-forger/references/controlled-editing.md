# 受控编辑与长文协议

仅在高风险文本、严格局部修改、结构化内容、多个版本或长文任务中读取本文件。普通短文本不需要加载这些细则。

## 1. 风险与规模判断

满足任一条件即按高风险任务处理：

- 合同、制度、政策、监管、招投标、临床医疗、财务披露或对外正式声明；
- 数字、责任、条件、例外、引用或专有名词密集；
- 用户要求“其他字符不动”、逐字保真或需要可审计修改记录。

满足任一条件即按长文处理：

- 超过约 8,000 个中文字符或 5,000 个英文单词；
- 至少三个相对独立章节，且需要分工或并行；
- 原文、修订稿和全量核验无法安全地在同一工作上下文内完成。

规模阈值用于路由，不是质量豁免。短文本只要风险高，仍执行完整保护和验证。

## 2. 编辑契约与状态

开始前形成最小内部契约：

| 字段 | 内容 |
|---|---|
| 权威原稿 | 当前应以哪个版本为准 |
| 授权范围 | 全文、章节、段落、字段或指定词语 |
| 编辑模式 | 校对、轻度润色、受控重组或压缩 |
| 不可改内容 | 逐字冻结的区域和元素 |
| 允许变化 | 可调整的术语、结构、长度和格式 |
| 交付形式 | 净稿、差异、修改说明或新版本文件 |

内部状态只使用：`complete`、`partial`、`needs_confirmation`。仅当状态不是 `complete` 时向用户显示状态与原因。正文缺失、权威版本不明或授权范围无法识别时不得猜测。

## 3. 严格局部修改

1. 标记目标范围、允许替换项和排除区。
2. 对目标范围外内容建立冻结边界；不要顺手统一标点、空格或措辞。
3. 全局替换必须先检索全部命中，再排除引语、法规原文、文件名、代码和用户指定区域。
4. 修改后再次检索目标词和误改风险词，确认无漏改、无越界。
5. 可保存为文本文件时，用检查脚本的 `--mode exact` 和精确替换声明验证冻结区；缺少精确范围时不得把结果标为完整验证。
6. 优先交付差异或修改片段；只有用户需要时才重复完整文本。

## 4. 结构化内容

- **Markdown 表格**：保持列数、字段对应和分隔行有效；用精确替换授权需要改动的单元格，并检查未授权单元格内容没有换位。
- **JSON、YAML、XML**：仅修改用户授权的值，不改变键名、层级、顺序或数据类型；JSON 字段改动用精确替换声明，修改后用解析器验证。无法解析时不要把它当普通散文重写。
- **代码、公式和标识符**：默认冻结；只润色注释或指定字符串。
- **脚注和引文**：直接引语逐字冻结；移动论断时同步验证脚注锚点、引用编号及“论断—证据”对应关系。
- **标题与编号**：重组后检查标题层级、编号连续性、图表引用、附件编号和“见上文/下文”等指向。
- **占位符**：保留 `待确认`、`待核实`、`TBD`、`TODO`、`XXX`、`${...}`、`{{...}}` 等标记，不用合理猜测填充。

高风险材料不能只保护人名或机构名；应把“主体—责任”“条件—结论”“论断—引用”等完整绑定短语加入保护清单。自动检查只能验证已声明的不变量，不能替代语义审阅。

## 5. 多版本处理

区分原稿、修订稿、批注和参考材料。用户未指定权威版本且版本差异会影响内容时，只问一个聚焦问题。整合时：

- 以权威原稿为基线；
- 已接受修改可以合入，未决批注保持可见；
- 冲突信息不得自行择一；
- 不把旧版本内容静默写回新版本。

## 6. 长文分段与并行

1. 建立章节台账，记录章节 ID、标题、处理状态和跨章节依赖。
2. 提取一次全局共享卡：事实与数字清单、术语表、人物称谓、时态、风格、格式和不可改内容。
3. 按自然章节分段；每段携带共享卡、当前章节和必要的相邻章节摘要，不重复加载无关全文。
4. 只有至少三个章节相对独立、没有关键跨章节依赖且并行确实节省时间时才并行；并行单元共享同一编辑契约。
5. 合并时只处理术语、时态、衔接、重复和编号，不再次自由重写全文。
6. 对照章节台账逐项确认无遗漏、重复、截断和交叉引用失效。无法完整交付时必须标记 `partial`，不得把部分结果称为完整成品。

## 7. 压缩与重组

压缩前先列出不可丢失的事实、结论、条件、例外、责任主体和证据锚点。优先删除重复、空泛修饰和可由上下文恢复的表达。

如果目标篇幅与信息完整性不能同时满足：

1. 保留高优先级事实与限定；
2. 列出建议删减但尚未删除的内容；
3. 请求用户确认取舍，或明确说明未达到目标篇幅。

受控重组不得把前提、风险或反方证据移到不易察觉的位置，也不得通过标题改写改变原文重点权重。

## 8. 完成门禁

只有同时满足以下条件才标记 `complete`：

- 章节和授权范围覆盖完整；
- 数字、日期、单位、专名、引文、引用、限定词和占位符无未授权变化；
- 没有新增事实、结论、因果或责任判断；
- 标题、编号、表格、链接、脚注和交叉引用有效；
- 篇幅与格式符合要求，或已说明不能兼得的约束；
- 所有疑似事实错误和版本冲突均已保留并列入待确认项。

验证失败时只对异常位置进行定向修复并重新验证，不自由重写全文。同类异常反复出现、授权边界不清或继续修复可能引入新漂移时停止，保留原文、降级为最小校对，或以 `partial` / `needs_confirmation` 交付。
