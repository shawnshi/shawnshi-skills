# Smart LaTeX Publisher

## 排版依据（必读）

排版前完整读取当前运行时的 `pai/WRITING.md`；若受信上下文已载入其当前全文，可直接复用。无法读取时停止排版定稿并报告缺项，不用旧摘要替代。下列条目只是 LaTeX 执行映射；与当前合同不一致时，以当前合同为准，不修改该治理文件。

明确用户指令、用户提供的模板或明确的出版方、期刊、法律、品牌规范只覆盖冲突条款，其余条款继续适用。记录语言和例外来源；预置模板本身不构成覆盖理由，不能因选择 `academic`、`cv` 或 `book` 就默认豁免排版要求。

- **中文与混排**：中文与 Latin 字母、中文与数字、数字与单位之间留一个空格；数字与 `%`、`°` 之间不加空格，中文全角标点两侧不加空格。按所在句段选择中英文标点，保留官方拼写和大小写。
- **英文正文**：分页文档普通正文采用 `10–12 pt`，实际基线距离为字号的 `120–145%`，每行目标为 `45–90` 个字符。混排按所在句段适用，不把这一行长目标硬换成中文字符数。标题、图注、脚注和代码不机械套用普通正文指标；核对实际字体与列宽，不按模板名推定合规。
- **行距与对齐**：在正文正常字号生效的位置核对 `\baselineskip` 与 `\f@size` 的比值；CTeX、字号切换和宏包可能改变结果。`\onehalfspacing` 或 `\linespread{1.3}` 的名称或参数不等于实际行距比例。英文正文默认左对齐，可使用本地已具备的 `ragged2e` / `\RaggedRight`；若明确规范要求两端对齐，则启用对应语言的断词并检查断词结果。不得因缺包自行安装。
- **文字与结构**：英文默认美式英语；标题采用句式大小写，排版正文使用弯引号，区分连字符、范围短横线和破折号，保持列表、图表标题及参考文献结构一致。完整句列表项加句号，短语项不强加。代码、URL、邮箱、文件路径、标识符、引用键、来源引文及数学内容保持原样；只在普通正文的任务副本中处理标点与空格，不做无差别全局替换，也不擅自改写事实或论点。

## Procedure

1. 确认目标类型、模板、语言、纸张、引用格式、公式密度和交付格式。未指定时，根据内容选择最接近的模板并说明。
2. 从 `templates/` 选择 `academic.tex`、`cv.tex`、`tech_report.tex`、`book.tex` 或 `tech_book.tex` 作为起点。样式选择参见 `references/styles.md`；逐项比较字体、字号、正文行距、列宽及对齐与当前排版合同，不把模板默认值视为已验收值。
3. 保留标题层级、公式、表格、图片、交叉引用、脚注和参考文献语义。需要成语或特殊中文处理时使用 `scripts/process_idioms.py`。
4. 检查 Python 和可用 TeX 引擎；不得在未获授权时安装发行版或包。
5. 使用 `scripts/smart_engine.py` 在当前任务临时目录转换和编译，并把最终 `.tex`、PDF 和必要资源写入用户指定目录或当前工作区。保留输入标题、作者、日期、摘要和正文；仅显式 `--title` / `--author` 覆盖对应元数据；`academic` 的摘要不依赖标题，无标题时仍输出摘要且不生成标题块。图片从输入目录解析并提取到输出目录的 `media/`，生成的绝对资源引用在移动交付目录后需要重定位。
6. 在生成的 `.tex` 任务副本中落实适用的排版要求；不直接改写原件或共享模板。当前 `scripts/smart_engine.py` 不自动实施 `WRITING.md` 的语言与排版规则，不能仅凭 CLI 退出码宣称符合合同。调整后用该模块的 `compile_tex()` 重新编译，保留原有超时与禁用 shell escape 的边界。
7. 读取编译日志，修复未定义命令、缺包、引用、字体、溢出和编码错误。不要用删除内容的方式掩盖编译错误。
8. 实际打开或渲染最终 PDF，检查首末页、分页、溢出、密集表格、实际字体/字号/行距、公式、图片和书签；复核语言、标题大小写、引号、横线、单位间距和重复空格。物理文件存在且可读只是必要条件，不能仅凭编译成功或文本抽取通过宣称排版完成；视觉检查未执行时明确标为未验收。中文内容验收须核对 UTF-8 输入及 `.tex`，检查日志的 `Missing character`、字体嵌入和渲染图；文本提取须使用已验证支持该 PDF 中文字体的提取器。若单一提取器漏字，使用本地可用的独立提取器（如 PyMuPDF、pypdf）交叉验证，不据此删除内容或修改正常模板。本机 Git 自带 `pdftotext` 曾漏提取实际存在的中文，不能单独作为中文丢失的判据。

大型文档可以按章节独立处理；只有并行能力可用且合并边界清楚时才并行。

## Dependencies

- Python 及脚本依赖。
- 可用的 LaTeX 发行版和所需字体。
- 模板要求的宏包。

依赖缺失时，交付可编译性已检查的 `.tex` 源文件和明确缺项，不自动安装，也不把在线编译器当作已完成结果。

## Boundaries

- 不为模板或输入启用 `-shell-escape`；需要执行外部命令的宏包只能交付 `.tex` 并明确说明未编译原因。
- 不默认写入知识库或保存排版偏好。
- 不更改数学含义、引用键或数据。
- 临时日志留在任务临时目录；最终产物进入用户指定位置。
- Pandoc 单次限时 60 秒，XeLaTeX 每轮限时 40 秒、最多两轮。缺失程序或超时明确报告失败；转换失败退出码为 1，编译函数返回 False，CLI 退出码为 1。不得把残留 PDF 当作本次成功产物。

## Output

交付 PDF、`.tex`、资源清单、编译状态和仍需人工处理的问题；注明本次采用的 `WRITING.md` 版本、语言分流、例外来源及实际完成的排版/视觉检查，不把待验收项写成通过。
