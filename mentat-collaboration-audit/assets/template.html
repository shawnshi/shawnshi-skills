六个结果问题

默认正文是待补证据的骨架，不是已完成审计。每项结论旁列证据指针、来源声明／已核验出处、分子／分母、覆盖与未知；缺证据不填零、不判通过、不合成总分。

1. 哪些任务已完成，哪些仍未解决？

不可用：缺少根任务结局与验收证据。已验收、失败、阻塞、放弃、未完成与未知分列；任务分母、已分类分母及未见结局数量未知。

2. 哪项有证据的可避免摩擦代价最高？

不可用：缺少可比较的影响证据。绑定 F-xx、直接观察的代价单位与比较范围；不能排序就保持未知，不用消息数估算注意力时间或金额。

3. AI 把哪些工作转交给了用户？

不可用：缺少纠错、恢复、重复授权与合理需求变更的出处。介入及返工各自的有效注释／已知原因／未知原因分母未知，不代表全部消息或修订。

4. 哪些必要的人类决策必须保留？

不可用：缺少授权与决策证据。保留目标选择、实质范围变化、必要审批、独立审查与安全停止；不记作浪费，不笼统要求“更自主”。

5. 上次整改得到了什么后续检验？

不可用：缺少 R-xx、版本、失败签名及 cohort。暴露／可比后续／实际观察分母、复发分子和观察覆盖未知；无暴露时复发数／率不可计算。实现测试与运行验证分列，不证明收益归因。

6. 下一项唯一实验是什么，什么结果会推翻它？

待定：证据不足。足够时只选一个 SYSTEM 修复或 USER 使用动作，列所有者、最小变化、预期方向、同类比较与混杂因素、质量／安全护栏、停止／回滚／证伪条件及后续状态。实践步骤见 IMPROVEMENT.md，不默认采集或保存。
