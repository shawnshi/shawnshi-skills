不可用：缺少根任务结局与验收证据。列已验收、失败、阻塞、放弃、未完成和未知；任务分母、已分类分母及未见结局数量均未知，工具成功不代表任务完成。

### 2. 哪项有证据的可避免摩擦代价最高？

不可用：缺少可比较的影响与归因证据。绑定 F-xx、直接观察的代价单位与比较范围；无法排序就说明未知，不以消息数估算注意力时间或金额。

### 3. AI 把哪些工作转交给了用户？

不可用：缺少介入／返工原因和出处。区分纠错、恢复推动、重复授权与合理需求变更；介入有效注释／已知原因／未知原因、返工有效注释／已知原因／未知原因均未知，不代表全部消息或修订。

### 4. 哪些必要的人类决策必须保留？

不可用：缺少授权范围与决策证据。保留目标选择、实质范围变化、必要审批、独立审查与安全停止；不得将它们记作浪费，也不建议笼统地“更自主”。

### 5. 上次整改得到了什么后续检验？

不可用：缺少 R-xx、修复版本、失败签名及 cohort 的可比后续暴露。提供暴露／可比后续／实际观察分母、复发分子和观察覆盖，当前均未知；无暴露时复发数／率不可计算。实现测试与运行验证分列，未复发不证明收益归因。

### 6. 下一项唯一实验是什么，什么结果会推翻它？

待定：证据不足，尚不能选择实验。证据足够时仅选一个 SYSTEM 修复或 USER 使用动作，写明所有者、最小变化、预期方向、同类比较条件与混杂因素、质量／安全护栏、停止／回滚／证伪条件及后续状态。使用 IMPROVEMENT.md 的动作卡，不默认采集或保存。
