# 原创平面视觉提示词

把用户意图转化为可执行的视觉方案，同时保持原创性、约束一致性和载体适配。不要把形容词数量当作质量。

## 选择执行路径

- **提示词路径**：用户只要提示词时，输出正向提示词和必要的负面约束，不调用图像生成。
- **生成路径**：用户明确要求生成图片时，直接使用当前图像生成能力；不要因主题简短而停下确认。
- **编辑路径**：用户要求编辑图片时，必须先确认目标图片可用并检查内容，再区分“必须保留”和“允许改变”的部分。

若用户要求的是精确数据图、技术架构图、流程图、可编辑矢量图、写实摄影或复杂三维渲染，交给更匹配的能力，不要强行套用本 Skill。

## 建立约束

从输入中提取：主题、载体、受众、情绪、画幅、视觉焦点、必须出现项、禁止项、文字、品牌资产和安全区。主题是唯一必需输入；其他信息可按载体合理补足，但不得覆盖明确要求。

按以下优先级解决约束：

1. 安全、授权和原创性边界；
2. 用户明确的禁止项；
3. 用户给出的数值规格、源图和必须保留项；
4. 用户明确要求出现的内容和文字；
5. 载体默认值；
6. 模型推断。

发现冲突时不得静默选择：

- 能安全降级且不改变核心意图时，说明一个必要假设后继续，例如生成无字底图并预留后期排版区。
- 冲突会实质改变交付且不存在明显安全默认值时，只询问一个阻断性问题。
- 用户明确要求不提问时，选择风险最低且可执行的方案，并在结果中简短标明被替代的约束。

需要载体默认值和安全区时，读取 [references/carrier-guides.md](references/carrier-guides.md)。

## 原创与品牌边界

- 用户要求模仿具体在世创作者时，不在最终提示词中使用其姓名，也不声称复制其独特风格；改写为较宽泛、可观察的构图、媒介、色板、线条和时期特征。
- 用户要求复刻现有海报、封面、角色标识、商标或品牌视觉时，不复制其构图、标志轮廓、字体字标或识别性组合；提供保留主题功能的原创替代。
- 用户提供并确认可使用的源图、Logo或品牌资产时，可以按其编辑要求保留和布局，不得自行重绘、变形或添加未提供的品牌资产。
- 公版主题可以重新诠释，但仍应采用原创构图。
- 不主动引入用户未要求的品牌、人物、角色、作品或敏感符号。

需要视觉特征词汇时，读取 [references/visual-language.md](references/visual-language.md)。参考只用于组合设计特征，不作为复制对象。

## 文字策略

在以下模式中选择一种：

- **无字图**：画面不生成文字、字母、数字、Logo或水印。
- **短文字尝试**：仅适合简短标题；必须提醒成图后核对拼写，不能承诺准确。
- **后期排版**：精确中文、多行标题、长文本、品牌字标或印刷交付默认采用；生成无字底图并明确预留区域、对齐和对比度。

用户同时要求“精确长文字”和“图中无文字”时，默认采用后期排版。详细规则见 [references/text-and-qa.md](references/text-and-qa.md)。

## 输出契约

用户没有指定格式时，提示词路径输出：

```text
正向提示词：主题与载体；原创视觉焦点；构图和负空间；色板；媒介与纹理；文字策略；画幅与安全区。
负面约束：与主题冲突的内容、禁止项、伪文字、未经提供的品牌资产及不适用的视觉效果。
参数：载体、画幅、文字策略。
假设或风险：仅在发生降级、冲突或存在不可验证事项时输出。
```

用户说“只要提示词”时，删除解释性内容，但保留会改变结果的假设和负面约束。不要承诺模型必然实现精确文字、Logo、手部或复杂布局。

## 生成与编辑后的检查

图片结果对当前执行者可见时，检查：主题和焦点、画幅、文字、禁止项、品牌资产、明显伪影和安全区。发现关键违约时最多自动修订一次；仍不满足时明确指出未解决问题，不反复生成。

工具不可用时，降级交付可直接使用的提示词并明确“未生成图片”。缺少必须的编辑源图时，停止并请求用户重新提供。

除非用户明确要求，不保存提示词偏好、不写入知识库，也不创建与当前交付无关的持久文件。

## 可选确定性脚本

需要列出现有视觉语言、校验画幅和方向、生成结构化提示词骨架或JSON时，可运行：

```bash
python3 scripts/generate_prompt.py --help
```

脚本无第三方依赖，会拒绝非法画幅、方向冲突、文字策略冲突和必须项/禁止项冲突。它提供结构骨架，不替代语义设计判断；最终结果仍需人工检查。

需要示例时只读取 [references/prompt-examples.md](references/prompt-examples.md)，不要机械复制示例主题。

版本和运行环境见 [references/release-notes.md](references/release-notes.md)。

## 完成检查

- 载体、画幅、方向和安全区一致。
- 主题、焦点、必须项和禁止项没有冲突。
- 文字模式明确，精确长文字已转为后期排版。
- 没有具体在世创作者姓名、未授权复刻或擅自添加的品牌资产。
- 提示词包含可观察的构图和媒介信息，而不是空泛风格词。
- 用户要求生成或编辑时已执行对应路径，或明确说明工具/源图阻断。
