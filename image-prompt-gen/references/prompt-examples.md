# 原创提示词示例

示例只展示决策结构。执行真实任务时使用用户主题和约束，不复制示例内容。

## 文章头图：数据治理与AI

```text
正向提示词：16:9横向医疗管理文章头图；以规整的数据模块形成稳定底座，上方少量抽象智能节点逐步亮起，表达“治理完成后能力扩展”；主体位于左侧约60%，右侧约35%保持低细节深蓝底色作为后期标题区；深蓝、青绿、冷白三色；编辑式平面插画、统一细线、轻微半色调颗粒；无人物、无文字；原创构图。
负面约束：医生或患者肖像、机器人、大脑和芯片俗套图标、写实摄影、复杂三维渲染、霓虹赛博朋克、文字、数字、Logo、水印、占用右侧安全区。
参数：文章头图，16:9，后期排版。
```

## 虚构书籍封面

```text
正向提示词：虚构小说《海岸以北》的2:3竖版封面底图；一枚旧钥匙与海岸线在负空间中形成双重轮廓，单一焦点，大面积米白留白；炭灰、海蓝、赭石三色；木刻线条与纸张纤维；上方为书名、下方为作者名保留排版区，不生成任何文字；原创文学封面。
负面约束：现有书籍版式、出版社标识、人物面孔、摄影拼贴、伪文字、Logo、水印、复杂背景。
参数：书籍封面，2:3，后期排版。
```

## 虚构专辑封面

```text
正向提示词：虚构器乐专辑“Midnight Transit”的1:1方形封面底图；单一圆形轨道被一条偏置亮线切开，形成夜间移动和停顿的视觉隐喻；深靛蓝、暖灰、暗金三色；几何极简、细微套色偏移和纸张颗粒；无人物、无文字、原创构图。
负面约束：复制现有唱片封面、唱片公司标识、乐队Logo、棱镜和彩虹等识别性组合、照片人像、文字、水印。
参数：专辑封面，1:1，无字图。
```

## 约束冲突的安全降级

用户同时要求“完整三行中文标题”和“图中不出现任何文字”时：

```text
假设：采用无字底图，三行标题改为后期排版；保留三行连续安全区。
正向提示词：9:16竖版封面底图；……；顶部保留三行标题安全区，生成阶段不渲染任何字符。
负面约束：任何文字、字母、数字、乱码、Logo和水印。
```

## 创作者模仿请求的原创转写

用户要求严格模仿具体在世创作者并复刻现有海报时，不复述其姓名到最终提示词。改写为：

```text
原创另类海报；超极简平面构成、图底反转、两色丝网印刷、单一象征物和大面积留白；采用全新主体轮廓、元素位置和视觉层级，不复制现有海报、角色标识、标题字标或演员肖像。
```
