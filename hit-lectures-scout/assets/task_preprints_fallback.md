# 预印本检索降级参考

当专用检索接口不可用时，使用当前环境真实可用的网页或文献检索能力查询 arXiv、medRxiv、期刊页面或作者公开材料。不得伪造结果，也不得假定某个工具名存在。

## 1. 检索范围

- 按用户指定的日期、主题、疾病、数据类型或方法检索。
- 核验预印本标识、版本日期、作者、摘要页和可用全文。
- 查询是否存在后续会议版或同行评审期刊版，并进行版本去重。

## 2. 纳入与评价

- 可以纳入临床验证、模型评估、方法、系统、数据集和基础研究，只要与问题相关。
- 不强制真实世界证据、受试样本量或显著性检验。按研究设计记录适用字段。
- 明确标注“预印本，未经同行评审”，不把探索性结果写成临床结论。
- 不因材料缺少商业映射而排除，也不生成针对特定厂商的攻击或销售话术。

## 3. 建议记录字段

```markdown
### [论文原标题 / 中文翻译标题]
- **状态**: [预印本；版本号；是否发现后续同行评审版本]
- **发布日期**: [YYYY-MM-DD]
- **标识与原始链接**: [arXiv ID/DOI/URL]
- **研究问题与设计**: [方法、系统、模型、观察性研究等]
- **数据、样本与统计量**: [适用且原文报告时填写；否则写“不适用”或“未报告”]
- **核心结果**: [原文支持的结果]
- **局限与复现信息**: [偏倚、外部验证、代码/数据可得性]
- **任务相关性**: [中性说明]
```

返回符合标准的实际数量。空结果时报告已查范围和限制，不扩展到低质量材料补齐。
