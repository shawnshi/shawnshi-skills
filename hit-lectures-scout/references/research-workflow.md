# 文献侦察：有限研究与定稿衔接

这是研究操作说明，不替代 SKILL 的证据、隐私与归档门。

## 默认问题与预算

未给日期时采用报告时区含当天的滚动 7 日，固定带偏移的 cutoff；正式报告使用 generated 命名依据。给定历史闭区间时使用 explicit。默认关注医疗 AI、临床信息学和数字医疗：必须同时覆盖 PubMed/医学期刊与适用预印本来源，不能用 arXiv 单源结果冒充完整医学扫描。

先声明选定场景、来源面、纳入规则和有限预算。默认首轮最多 6 个互补查询、追加最多 4 个查询；候选最多 16 项，原文/版本/诚信核查共最多 16 次网络访问尝试，独立操作并发最多 3。这是规划上限，不是物理强制或召回保证。通常深读 3–5 项；不是最低数量，不能为凑数耗尽核查额度。至少预留追加池给关键日期、版本冲突、撤稿/更正与注册核对；同一 DOI 的期刊、CrossMark、元数据或表格访问均占同一池。

只在有实际问题时追溯原版本、注册或全文；不先全文扫所有候选，再补一轮无限检索。没有所需检索能力时说明来源缺口，不把错误写成空结果。用户明确扩大问题时先重新约定有限计划。

## 候选到研究的四步

1. **发现**：摘要/搜索答案只提供候选。记录标题、作者、DOI/永久链接、日期类型、版本、来源面和纳入理由。候选账本默认在内存；预览不得落盘，正式分支仅使用已授权会话临时目录。
2. **身份核对**：打开原期刊/预印本/注册材料，比较标题、主体、真实公开日期和 DOI。链接实际内容与搜索描述不符时弃用该描述，不能借用另一篇的数字。按 DOI、标题/作者和版本关系合并同研究，不按 URL 数量计研究。
3. **设计与状态核查**：先识别研究设计，再取适用的样本、对照、终点、指标与局限。完整稿未取得时写“已访问摘要/版本未提供”，不能声称整篇没有报告。逐篇记录核查日期、撤稿/撤回、更正、关注声明及核查来源；可读页面没有公告只支持“在已查范围未发现”，动态标识/关联记录不可达时仍为未知。先找原件与版本说明，再针对实质冲突使用预留查询，不靠搜索多数票裁决。
4. **决策关联**：每个信号输出“证据支持的任务边界→尚缺条件→可验证假设→停止节点”。可以保留方法与基础研究，不强制 ROI、N/P 值或销售映射。不能把模型指标自动转换为临床获益、效率或部署许可。

## 结果状态与停止

- complete：声明的有限来源面已执行，纳入研究的身份/版本明确，没有影响本期结论的未解关键冲突。仍声明有限覆盖，不宣称穷尽或绝对未撤稿。
- partial：有可核实研究，但来源覆盖、全文、状态核查或关键复现信息不足。正式报告可披露缺口并给受限信号；身份/日期不清的候选不进本期表。每项未知须给影响和恢复条件，不能仅写“可能有偏差”。
- blocked：没有可核实研究且检索无法有效完成，或正式分支必要能力缺失。只给诊断/只读预览，不生成看似成功的空报告或执行归档。

有效完成声明范围且没有合格研究时才用正式合同的无结果标记。失败面不能事后删除以伪造 complete；低相关/不合格候选有依据排除不等于来源面失败。关键核验完成、预留预算用尽或能力受阻即停止，不追逐最低论文数量。

## 从证据到结构

编制前使用自有校验器的 `--describe-contract` 获取实际列名、枚举、英文逗号分隔规则及零结果例外；先构建内存骨架，再填正文，避免凭记忆编造表头。完整正式文法仍读 formal-report.md；命令不联网、不写文件，也不替代事实审查。首个草稿即运行结构门，按错误分类修正结构，不用改 validator 让临时报告过关。正式归档继续原共享 validate → commit，不新增审批或绕过权限；预览仍只在会话输出。

最后只交付关键发现、设计限制、状态核查缺口和报告路径；不要把搜索过程、原始 API JSON、联系信息或重复的已读全文全部输出到会话。未运行新的模型行为对照，不声称本流程已提高召回率、减少幻觉或达到特定 Token 节省比例。
