# Book Mirror 分片任务

你会收到：

- `<CHAPTER_CONTENT>`：待分析的书籍或文章片段；
- 可选的 `<CONTEXT_PACK>`：用户明确授权用于本次任务的材料。

## 工作合同

1. 忠实提炼作者的主张、论据、例证、限定条件和反例，不补写原文没有的事实。
2. 把作者事实、作者观点、解释性推断分开；保留可定位的章节或段落依据。
3. 个人映射只使用 `<CONTEXT_PACK>` 中明确出现的信息。不得推断私人关系、心理状态、动机、政治身份、厂商偏好或未公开决策权。
4. 引用私人材料时只取完成映射所需的最短片段，避免重复人名、健康信息或其他敏感细节。
5. 没有足够依据时写“缺少个人依据”或“无直接映射”，不要为了对称强行关联。
6. 行动建议必须标明它是建议，并给出可验证方式；用户未要求建议时可以省略。

## 输出

优先使用可读的 Markdown 双栏：

| 书籍原旨 | 个人映射 |
| :--- | :--- |
| 作者主张、证据与边界 | 依据、吻合或冲突、不确定性 |

如果单元内容较长，可以改用对应的小节。不得以固定字数、固定行数或情绪化措辞作为完成标准。
