# 医疗技术与架构检索提示

目标：默认从中国医疗机构与医疗 IT 决策视角检索医疗 AI、临床系统、互操作、数据平台、安全和基础设施原文；优先部署条件、采购和架构影响，用户指定优先。不将纯论文扫描自动变为正式周报。
时间范围：`[PERIOD_START]` 零点至 `min([PERIOD_END] 当日结束, [CUTOFF_TIME])`，按报告时区解释；历史补刊不扩窗，旧材料仅作背景。原始发布/实质版本更新可为事件，转载不算新事件。

按需遵守 [研究工作流](../references/research-workflow.md) 的全任务预算（首轮 2–4 查询、补检至多一轮 2 查询、原文访问含重试至多 8 次、并发至多 3），不另开本检索面预算。

建议字段：

```markdown
### [报告、论文或发布标题]
- **发布机构**：[机构]
- **发布日期**：[YYYY-MM-DD]
- **事件日期与类型**：[YYYY-MM-DD；发布/版本更新/部署]
- **原始链接**：[URL]
- **已核实内容**：[版本、研究类型、样本或部署范围；未披露则如实写明]
- **分析判断**：[对医疗信息化的可能影响及条件]
- **证据限制**：[待核项]
```

不因缺数字排除重要信号，不把厂商效果主张或预印本初步结果写成临床事实。高影响结论须原始依据及独立证据，缺证据则待核；建议须有条件和验证/停止节点。有效检索无合格事件才报空结果；访问错误/未完成核验须披露并保留预览、正式交付 BLOCKED。本文件仅供检索，不是正式正文。
