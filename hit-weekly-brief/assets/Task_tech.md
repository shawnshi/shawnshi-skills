# 医疗技术与架构检索提示

目标：检索与本期主题有关的医疗 AI、临床信息系统、互操作、数据平台、安全和基础设施原始材料。
时间范围：`[PERIOD_START]` 至 `[CUTOFF_TIME]`。

建议字段：

```markdown
### [报告、论文或发布标题]
- **发布机构**：[机构]
- **发布日期**：[YYYY-MM-DD]
- **事件日期**：[YYYY-MM-DD]
- **原始链接**：[URL]
- **已核实内容**：[版本、研究类型、样本或部署范围；未披露则如实写明]
- **分析判断**：[对医疗信息化的可能影响及条件]
- **证据限制**：[待核项]
```

不要因为没有数字而排除重要信号，也不要把研究机构、厂商或媒体主张改写成事实。没有合格结果时报告空结果。
