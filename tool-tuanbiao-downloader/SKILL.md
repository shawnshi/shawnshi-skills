# TTBZ Image-based Standard Downloader

## Procedure

1. 确认标准编号、发布机构、目标版本、来源许可和输出目录。仅接受已核实属于 `https://www.ttbz.org.cn/kkfileview/{path}/` 的公开图片查看链接或该平台的单段路径 ID（不是通用标准编号）；确认其页面使用 `{i}.jpg` 图片序列。不得将其他站点、普通 PDF 链接或 GB、ISO 等编号直接传给专用脚本，也不得猜测编号到路径 ID 的映射。
2. 不符合上述格式或无法核实来源时，停止专用脚本流程；仅通过用户已授权且当前可用的通用能力另行处理，否则说明不支持及所缺信息。记录已核实的来源 URL、访问时间和版本信息。
3. 检查 Python 与 `scripts/requirements.txt` 中的依赖。不得在未获授权时安装或升级依赖。
4. 在已确认的输出目录作为工作目录运行 `python <技能目录>/scripts/downloader.py <已核实的路径ID或查看链接>`；可用 `--start N` 指定起始图片索引，默认 0。脚本固定请求 `https://www.ttbz.org.cn/kkfileview/{path}/{i}.jpg`，在工作目录创建路径 ID 图片目录及同名 PDF，无任意站点下载或输出目录参数。批量任务只有在目标相互独立、来源允许并发且并行能力可用时才并行；脚本固定 0.1 秒间隔不代表满足站点速率要求，不满足时不运行。
5. 验证响应确为图片，再验证生成 PDF 的文件头、文件大小、页数和可读性；这些不是脚本自动保证的校验。连续三次错误后的停止不证明已到末页，应对照来源页数检查缺页；失败或未生成 PDF 时不得报告成功。可以计算哈希用于去重和完整性记录。
6. 图片按原始页序合并，并检查页码、目录和重复页；避免混入旧任务或无关图片。故障处理见 `references/troubleshooting.md`。
7. 将最终 PDF 写入用户指定目录或当前工作区，输出成功、失败和需人工处理的编号清单。

## Boundaries

- 不绕过登录、验证码、付费、访问控制或 robots/站点限制；公开可访问不等于允许下载或再分发，须遵守版权和来源许可。
- 不承诺所有编号都能下载。遇到未公开、下架、权限限制或来源失效时，报告原因和合法替代路径。
- 不根据编号伪造标准名称、状态或正文。
- 不默认保存执行遥测、标准内容或元数据到知识库。
- 大批量抓取前确认数量、速率和来源许可。

## Output

交付已验证的 PDF、来源与版本清单、哈希或页数校验，以及失败诊断。
