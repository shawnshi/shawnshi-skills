# 输出结构与决策模板

## 通用规则

- 先回答用户真正需要作出的判断，再解释方法。
- 在标题或开头注明市场范围、信息截止日期和版本。
- 关键事实与数字就近引用；估算显示公式、区间和置信度。
- 表格只承载比较，不在正文重复所有单元格。
- 不使用装饰性emoji，不使用“冷峻”“致命”等带有结论偏置的措辞。
- 用户提供指定结构时优先遵循，但不得省略范围、证据、假设和限制。

## 一、单点回答

1. 直接结论；
2. 2—4条关键证据；
3. 口径、假设或不确定性；
4. 对决策的含义。

不要自动扩展成完整行业报告。

## 二、快速扫描

### 研究范围

用一小段说明市场定义、地域、截止日期和默认假设。

### 核心判断

输出3—5条有信息量的判断。每条包含“结论—证据—影响”。

### 市场与玩家

只呈现最关键的规模信号、需求变化和3—5个代表性玩家。明确清单是否完整。

### 机会、风险与未知项

区分结构性机会、执行摩擦、系统性风险和最可能改变结论的未知信息。

### 下一步

给出1—3个最小验证动作。

## 三、标准研究

### 执行摘要

- 一句话结论；
- 3—5项关键发现；
- 推荐决策及其前提；
- 最大风险和需验证事项。

### 1. 范围与方法

说明市场边界、地域、截止日期、受众、数据口径、来源层级和主要限制。

### 2. 市场结构与经济性

按需覆盖规模、细分、需求侧、采购机制、价值链、商业模式、利润池和进入壁垒。

### 3. 竞争格局

说明玩家类型、集中度、竞争变量和变化方向。需要厂商比较时披露纳入条件、指标和证据缺口。

### 4. 情景与演化路径

给出基准、乐观、压力情景，以及领先指标和失效条件。

### 5. 机会与风险

分别评估机会规模、可进入性、时间窗口、主要摩擦和缓释条件。

### 6. 决策建议

列出推荐选项、备选项、不行动后果、阶段动作、决策门槛和责任角色。

### 7. 假设、未知项与来源

列出可能改变结论的假设、证据缺口和关键来源。

## 四、深度研究附加项

在标准研究基础上增加：

- 市场规模计算表与三角校验；
- 厂商完整评分卡和证据强度；
- 情景参数与敏感性分析；
- 价值链、利润池和单位经济性；
- 主要结论的替代解释和红队结果；
- 精简证据台账及计算附录；
- 更新触发条件和持续监测指标。

## 五、按决策场景调整

| 场景 | 重点增加 | 避免 |
|---|---|---|
| 市场进入 | 细分吸引力、进入壁垒、渠道、进入顺序、资源需求 | 只给宏观趋势 |
| 产品战略 | 客户任务、替代方案、差异化、路线图、定价与验证 | 只比较功能清单 |
| 供应商选型 | 客户适配、TCO、实施、SLA、迁移、锁定和验收 | 将公开资料初筛写成正式评标 |
| 投资初筛 | 增长质量、商业模式、资本需求、壁垒和下行情景 | 给出个性化买卖指令或保证回报 |

## 六、增量更新

更新既有报告时：

1. 核对并沿用已确认的市场定义、地域、指标和评价方法；
2. 只检索上版截止日期之后的新事实，以及需要纠正的旧事实；
3. 区分“新增”“修正”“失效”和“无实质变化”；
4. 说明新证据是否改变原有结论、置信度、建议或决策门槛；
5. 输出简洁的版本变化表和下一次更新触发条件。

市场定义或方法发生变化时，不得伪装成同比更新；应说明不可比原因，并在必要时重建基线。

## 七、行动建议格式

对每项建议说明：

| 字段 | 内容 |
|---|---|
| 动作 | 做什么 |
| 理由 | 哪些证据支持 |
| 时间 | 立即、30天、90天、180天或行业适配周期 |
| 责任角色 | 谁推动、谁验证、谁决策 |
| 决策门槛 | 达到什么条件继续或停止 |
| 指标 | 领先指标和结果指标 |
| 风险 | 最大失败方式及缓释措施 |

建议数量服从优先级，避免用大量低价值动作稀释关键决策。
