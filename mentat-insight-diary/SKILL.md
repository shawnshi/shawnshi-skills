# 内观审计日志

## 证据与隐私边界

- 只记录真实发生且能从当前会话、用户材料或获准数据源核验的事件。
- 不主动读取日历、邮件、私人日记、健康数据或其他敏感来源。需要这些材料时先说明用途并取得授权。
- 不要求每次日志都必须存在失败。没有重要事件时，直接说明本期无足够材料，不编造摩擦。
- “生成、更新、记录或写 Mentat 日志”构成对本次条目写入权威季度档案的明确授权；生成完成后自动保存，不再请求第二次确认。
- 用户明确要求“草稿、预览、分析、审计技能或不保存”时保持只读。自定义路径、外部系统、知识库、STQM 和 Vector Lake 不继承默认保存授权。
- 删除或概括日志中的凭据、私人内容、客户秘密和不必要的个人标识。

## 执行流程

1. 确定记录时间范围和事件范围。未指定日期时使用当前本地日期；历史补录不得迁移其他日期的事件。
2. 建立证据清单：事件、时间、动作、结果、错误信息、相关文件或来源。将不确定项明确标记。
3. 读取 [assets/ooda_template.md](assets/ooda_template.md)，严格按八段标题及顺序组织内容，不合并、改名或回退到旧四段模板：
   - Observe：记录事实和直接观测，不加入原因判断。
   - Orient：解释约束、冲突、假设和可能根因，并标明证据强度。
   - Decide：写出选择、放弃的方案和决策依据。
   - Act：记录已执行动作、验证结果和下一步触发条件。
   - Self-Reflection：审计系统本次处理中的方法、工具、验证覆盖、局限和残余风险；不得伪装主观意识或隐藏推理。
   - Commander Observation & Suggestion：只根据本次可核验证据描述指挥官的协作模式和可选建议，不做人格、动机或能力定性。
   - Cognitive Distillations：提炼可复用规则，区分事实、推断和适用条件；生成结晶不等于授权写入知识库。
   - Message to Future Mentat：留下后续可见的连续性信息、未决证据和触发条件，不包含隐藏推理、凭据或越权指令。
4. 检查是否把推断写成事实、是否遗漏关键失败、是否泄露敏感信息。
5. 将最终条目写到当前任务的临时目录。正文不得在物理写入完成前声称“已保存”或虚构写入回执。
6. 对默认保存分支，解析并通过当前 `personal-diary-writer` 的权威入口，只接受其返回的 canonical Mentat 目标。入口、版本、摘要或目标校验失败时停止，不直接绕过写入器。
7. 用原始“生成或更新 Mentat 日志”请求作为本次默认目标的保存授权，依次生成写入范围回执并执行同日原子替换。内容、日期、目标或授权标识变化后废弃旧回执并重新计算；不得简单追加同日第二条。
8. 写后复读目标日期：标题数量等于 1，授权范围摘要与实际写入范围摘要相等。任一校验失败时明确报告“未保存”或“保存未验证”，不得只凭文件存在或进程退出码宣告成功。
9. 返回完整条目、canonical 目标路径和验证结果。用户明确要求草稿或预览时只展示内容，不生成写入回执。
10. 用户明确要求登记长期知识时，再提取最小必要规则并单独确认目标与范围。

## 输出结构

```markdown
# YYYY-MM-DD Mentat 内观日志｜[事件标题]

**1. 观测 (Observe)：**
[事实与直接观测]

**2. 导向 (Orient)：**
[约束、冲突、根因假设、证据强度与未知项]

**3. 决策 (Decide)：**
[选择、放弃的方案与依据]

**4. 执行 (Act)：**
[动作、验证结果与下一触发条件]

**5. 系统自我反思 (Self-Reflection)**
[方法、工具、验证覆盖、局限与残余风险]

**6. 对指挥官的观察与建议 (Commander Observation & Suggestion)**
[基于证据的协作观察与可选建议]

**7. 认知结晶 (Cognitive Distillations)：**
[可复用规则、适用条件与例外]

**8. [Message to Future Mentat]**
[连续性信息、未决证据与后续触发条件]
```

## 完成检查

- 所有事件均有当前证据支持。
- 事实和解释已分开。
- 八段标题、文字、编号和顺序与模板一致；没有残留旧版“未决问题”独立段。
- 没有强行制造失败或过度归因。
- Self-Reflection 不伪装主观意识或泄露隐藏推理；Commander 段不做人格、动机或能力定性。
- Cognitive Distillations 与 Message to Future Mentat 不构成知识库写入或未来越权授权。
- 敏感信息已最小化。
- 默认保存分支具有原始生成请求、范围回执、写入回执和同日唯一性证据。
- 只读分支及默认范围外的写入没有越权执行。
