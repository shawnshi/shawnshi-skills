# 真人审批接入与交接边界

适用于部署负责人接入审批或准备正式交付；普通草稿任务不加载。本候选包没有身份提供方或可信审批事件验证器，当前只能交付内部草稿与人工审核材料。CLI姓名和哈希都不是身份凭证；本文件是待实施接口契约，不是已实现能力。

## 当前可执行范围

模型可初始化、生成候选、普通校验、事务提交与准备审核交接。批准、mark-ready、外发生成、已批准稿修订由有权限的真人在受控终端执行。宿主必须把这些治理命令与模型可调用工具隔离；仅在提示词写“真人执行”不构成技术权限隔离。尚未实施隔离的宿主不得宣称具备真实审批权限控制，也不得开放自动审批。

## 接入方必须验证

| 验证对象 | 可信来源与验收要求 |
|---|---|
| actor_id、角色与当前授权 | 来自宿主已认证会话及权限服务，不接受模型生成的姓名、角色或本地JSON作为证明 |
| 审核对象 | context_id、artifact_type、content_version、body_sha256；信件同时绑定context_sha256；必须与实际当前稿一致 |
| approval_event_id、decision、时间/期限 | 来自审批服务的可验证事件；核对受众、用途、有效期和撤销状态；不得接受仅在命令行传approved |
| 执行边界 | 模型工具身份无治理命令权限；受控服务验证上述事件后才可调用本包治理脚本；只读草稿路径不需要审批权限 |
| 审计与失败 | 保留事件ID、真实账号、稿件绑定、验证结果及操作回执；无事件、账号越权、稿件变化或事件失效立即拒绝，不写文件 |

不要把密钥写入Skill、客户工作区或模型可读配置。具体认证协议由实际宿主决定；未给出宿主实现前不提供“模拟令牌”或可由模型自行填写的审批开关。

## 真人审核交接最小项

交付现有总报告及所引用底稿，列出主体/范围、版本、ready=false及缺口、事实与商业复核要点、一个主动作和实际负责人。文档中的哈希只能帮助辨识稿件，不能代替审核事件。真人分别确认关键事实、过期处理、行动与承诺边界；材料未完整提交不编造审核SLA开始时间。

## 接入验收（均待真实宿主执行）

1. 有权真人批准当前稿件成功，并可回查事件与实际稿件绑定。
2. 无事件、未知/越权账号、其他客户事件、过期/撤销事件均拒绝；原成果字节不变。
3. 审核后变更正文或信件上下文，旧事件不能批准新稿。
4. 模型工具直接尝试治理命令被宿主权限层拒绝，不能靠更换姓名绕过。
5. 验证服务不可用时保持草稿，不降级为字符串批准。

没有这些真实记录，R01保持未关闭；单元测试、模拟事件和本地CLI退出0均不能代替。
