# 隐私与科研图像完整性

## 敏感与未发表数据

- 最少字段、去标识、本地处理；默认不上传外部服务，也不交给不需要数据的子代理。
- 患者姓名、病历号、邮箱、电话及其他直接标识不得出现在标签、文件名、Job、命令行输入/输出路径、清单、日志或缓存。
- 未发表数据按用户授权范围使用；不要扩大共享对象或发布范围。
- 原始数据默认不进入交付包。敏感任务只保留必要的派生成品，结束时删除流水线缓存。
- 任意 Python 绘图脚本并不自带网络沙箱。敏感任务只在宿主已禁用出站流量的可信本地运行器中执行；无法核实时停止。
- 若任务必须外部共享或包含受限原始数据，先取得明确授权并说明范围。

## 显微、凝胶、印迹和其他证据图像

原始图像只读并保留。允许的处理必须对整幅图一致、可追溯且写入记录：

- 全局亮度/对比度调整；
- 裁切与旋转；
- 通道映射；
- 由元数据或标定得到的比例尺；
- 领域允许且清楚标界、完整声明的拼接。

全局调整必须声明 scope=global 和参数；裁切记录四个边界与原因；旋转记录角度；通道映射记录源到显示通道；比例尺记录校准来源、长度和单位。流水线递归哈希所有声明路径，并在构图前后复核；原图或数据被脚本改写时停止导出。

禁止选择性擦除、克隆、局部增强、未声明拼接、修改单个对象或用生成式模型编辑证据图像。没有校准信息时不能凭视觉估计比例尺。示意图或概念图必须明确标注为 schematic，不得伪装为观察数据。

这些门禁能发现声明缺失和运行期间的文件变化，但不能阻止恶意代码先修改再还原，也不能鉴定图像真实性。它不替代只读挂载、网络隔离、机构伦理、期刊调查或法证检查。遇到可疑操纵时停止“修复”，保留原文件并建议由研究诚信负责人复核。
