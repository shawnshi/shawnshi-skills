# Style 7: Clean Green

> 这是本技能维护的白底绿色极简主题。旧文件名仅为兼容既有引用而保留；本主题不代表任何第三方提供、认可或维护。

## 视觉目标

以白底、细边框、少量绿色强调呈现精确关系，适合 API 文档、白皮书、架构说明和密集语义图。颜色只用于区分已定义的关系，不用于暗示品牌或结论。

## 渲染器令牌

| Token | Value | Usage |
|---|---|---|
| Canvas / surface | `#ffffff` | 背景和节点 |
| Border | `#dce5e3` | 节点边框 |
| Text primary | `#0f172a` | 标题、节点主标签 |
| Text secondary | `#475569` | 说明、箭头标签 |
| Text muted | `#94a3b8` | 类型和次要信息 |
| Control | `#10a37f` | 主控制流 |
| Write | `#0f766e` | 写入 |
| Read | `#0891b2` | 读取 |
| Data | `#f59e0b` | 数据流 |
| Async | `#64748b` | 异步关系 |

默认节点圆角为 14px，默认箭头宽度为 2px。绿色只是本主题的视觉令牌，不是任何第三方品牌声明。

## 字体与层级

```css
text {
  font-family: "Helvetica Neue", Helvetica, Arial,
               "PingFang SC", "Microsoft YaHei", sans-serif;
}
```

- 标题：24px，左对齐。
- 节点主标签：14–16px，600。
- 节点说明：12–13px，400。
- 箭头标签和类型标签：11–12px。
- 保持足够留白；密集图通过分组、缩短标签和增加画布解决，不盲目缩小字体。

## 组件与容器

- 节点使用白色填充和细灰绿边框，不使用阴影和装饰纹理。
- 强调节点可以使用左侧色条或较深边框，但同图保持一致。
- 容器使用浅色或虚线边界；容器不得与节点边框竞争视觉层级。
- 数据库、状态和参与者等语义形状由图型适配器决定，不为追求统一而改回普通矩形。

## 箭头和图例

- 使用正交路线和简短技术标签。
- `control`、`write`、`read`、`data`、`async`、`feedback` 等关系必须与图例一致。
- 异步、可选或参考关系除颜色外还应使用虚线或明确标签。
- 白底上的标签仍需避让线条和节点；不能因背景为白色而省略碰撞检查。

## 适用与禁用

适合：API/集成关系、白底报告、流程图、时序图、ER 图和状态图。

谨慎：节点很多但标签很长的中文架构图，应先拆图或增大画布。

避免：把该主题称为任何产品或公司的“官方风格”，或用绿色表达未经定义的“通过”“安全”“合规”。
