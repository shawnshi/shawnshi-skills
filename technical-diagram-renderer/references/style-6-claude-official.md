# Style 6: Warm Editorial

> 这是本技能维护的中性暖色主题。旧文件名仅为兼容既有引用而保留；本主题不代表任何第三方提供、认可或维护。

## 视觉目标

用暖灰画布、克制边框和低饱和强调色呈现说明性技术图。适合报告、方案说明和面向非纯技术受众的架构图；语义仍由标签、线型和图例表达。

## 渲染器令牌

| Token | Value | Usage |
|---|---|---|
| Canvas | `#f8f6f3` | 背景 |
| Surface | `#fffcf7` | 默认节点 |
| Border | `#d9d0c3` | 节点边框 |
| Text primary | `#141413` | 标题、节点主标签 |
| Text secondary | `#6b6257` | 说明、箭头标签 |
| Text muted | `#a29a8f` | 类型和次要信息 |
| Control | `#d97757` | 主控制流 |
| Write | `#7b8b5c` | 写入 |
| Read | `#8c6f5a` | 读取 |
| Data | `#b45309` | 数据流 |
| Async | `#9a6fb0` | 异步关系 |

默认节点圆角为 10px，默认箭头宽度为 2px。不要把暖色、绿色或紫色自行解释为风险等级、系统归属或确认状态。

## 字体与层级

```css
text {
  font-family: "Helvetica Neue", Helvetica, Arial,
               "PingFang SC", "Microsoft YaHei", sans-serif;
}
```

- 标题：24px，左对齐。
- 节点主标签：14–16px，600。
- 节点说明：12–13px，400。
- 箭头标签和类型标签：11–12px。
- 每个节点优先 1–3 行；长中文先换行，再增加节点高度。

## 组件与容器

- 默认节点使用暖白填充和细暖灰边框，不使用高饱和渐变。
- 容器可用无填充、5/4 虚线边框；容器标题保持简短。
- 同一语义层的节点保持相同尺寸、圆角和文字基线。
- 强调节点只改变一项视觉变量，例如边框色或左侧强调条，不同时叠加阴影、渐变和粗边框。

## 箭头和图例

- 主关系采用正交走线，端点连接边中部。
- 读、写、数据、异步和反馈必须使用输入契约中的 `flow` 值。
- 两种及以上关系类型时提供图例；虚线关系在图例中也必须显示为虚线。
- 标签使用技术动词和对象，例如“写入索引”“读取病历摘要”，避免“处理”“发送”等含糊词。

## 适用与禁用

适合：概念架构、数据流、流程说明、少到中等密度的语义图。

谨慎：黑白打印、需要严格品牌色或法规规定配色的材料。

避免：用视觉样式替代业务确认；把该主题称为任何产品或公司的“官方风格”。
