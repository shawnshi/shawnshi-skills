## 3. 问题分级

| 级别 | 定义 | 处理 |
| :--- | :--- | :--- |
| `blocker`（阻断） | 可导致患者安全、重大合规/安全、业务中断或方案方向错误 | 修复并重新评审；不得通过 |
| `major`（主要） | 影响可实施性、可验收性或关键非功能目标 | 附责任人和期限整改；通常为附条件通过 |
| `minor`（次要） | 局部不完整，不改变核心设计结论 | 记录并在后续版本关闭 |
| `observation`（观察） | 可改善清晰度、效率或可维护性 | 由项目决定是否采纳 |

## 4. 结论规则

- **`pass`（通过）**：所有适用门禁通过，无未闭环 `blocker/major` 问题，且每个适用维度得分至少为 2。
- **`conditional_pass`（附条件通过）**：无 `blocker` 问题，但存在得分 1 或未闭环 `major` 问题；必须记录责任人、截止日期和复核证据。
- **`fail`（不通过）**：任一适用门禁失败、存在 `blocker` 问题，或任一适用维度得分为 0。
