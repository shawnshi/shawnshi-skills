# 证据与置信度标准

标准或深度模式、人物研究、来源冲突、敏感指控及高风险主题必须完整执行本标准。快速核验在不涉及上述情形时，只执行核心工作流中的分级验证规则。

## 1. 信源分层

按具体主张而不是机构整体声誉评价来源。

| 层级 | 典型来源 | 主要用途 | 注意事项 |
|---|---|---|---|
| S1 最终权威或原始记录 | 法律法规、监管决定、法院文书、政府统计原表、交易所披露、公司法定公告、标准正文、原始数据库 | 确认法定状态、正式数字、日期和直接行为 | 检查版本、适用辖区、统计口径和修订记录 |
| S2 一手研究或直接材料 | 同行评议论文、专利、官方技术文档、会议原文、经核验的机构声明 | 确认方法、技术能力、组织立场和原始发现 | 机构声明只能证明“其作出该声明”，不能自动证明声明内容为真 |
| S3 高质量独立解释 | 方法透明的智库、专业研究机构、行业数据库、高信誉新闻机构 | 补充背景、独立核验、利益与影响分析 | 核查引用链、作者专业性、资金或立场偏差 |
| S4 线索与立场材料 | 企业营销、倡议组织、社交平台、个人博客、论坛 | 发现线索、观察叙事和早期信号 | 不得单独支撑关键事实或敏感指控 |

不要设置固定域名白名单。优先使用与目标主张最接近、最原始、最具最终权威且方法透明的来源。

## 2. 来源独立性

只有满足下列条件时才视为独立来源：

- 具有不同的信息获取路径或独立分析方法；
- 不是转载、内容聚合或同一通讯社稿件的改写；
- 不共同依赖同一份未公开材料、匿名消息源或原始数据库摘要；
- 不属于同一联合发布、母子机构交叉引用或同一利益方的重复表述。

无法判断独立性时标记“独立性未确认”，不得计入双源验证。

## 3. 主张分级与最低证据

| 级别 | 判定 | 最低要求 | 未满足时的处理 |
|---|---|---|---|
| A 高影响主张 | 决定核心结论的争议事实、敏感指控、归因、预测或高影响判断 | S1 加一个独立 S2/S3 佐证，或两个独立的高质量 S1/S2；同时检索反证 | 标记“单一来源”或“待核实”，降低置信度，不得写入确定性标题 |
| B 重要支持主张 | 统计、趋势、市场变化和关键背景 | 一个合适的 S1/S2；若口径、方法或时效有争议，再增加独立来源 | 披露口径并避免过度外推 |
| C 确定性记录 | 法律文本、正式任命、法定披露日期、公开标准版本 | 一个具有最终权威的 S1 | 不能访问原文时寻找同等级镜像或标记未直接核验 |

来源数量只是最低门槛。若来源存在重大方法缺陷、利益冲突或陈旧信息，即使数量达到要求也不得提高结论强度。

## 4. 四类质量概念

### 来源可靠性

- 高：直接掌握信息，历史记录稳定，方法和责任主体透明；
- 中：总体可信，但获取链条、方法或完整性存在可识别局限；
- 低：匿名、方法不明、明显自利、历史准确性差或只能提供间接线索。

### 信息可信度

- 已确认：由最终权威记录确认，或得到独立高质量证据一致支持；
- 初步确认：内容合理且部分得到印证，但仍有重要缺口；
- 未核实：单一间接来源、无法打开原文或存在未解决的强反证；
- 已反驳：被更直接、更新或具有最终权威的证据否定。

### 分析置信度

- 高：证据质量高且相互独立，逻辑链清楚，关键假设少，没有决定性反证或重大情报缺口；
- 中：证据足以支持当前判断，但存在方法差异、未解决缺口、关键假设或合理替代解释；
- 低：证据稀少、主要依赖单一来源或间接推断，且结论对关键假设高度敏感。

不得因为来源机构知名、报告篇幅长或来源数量多而自动提高置信度。

### 事件发生概率

预测未来事件时使用一致区间：

| 表述 | 概率区间 |
|---|---:|
| 极不可能 | 1%—5% |
| 很不可能 | 5%—20% |
| 概率较低 | 20%—45% |
| 约各半 | 45%—55% |
| 较可能 | 55%—80% |
| 很可能 | 80%—95% |
| 近乎确定 | 95%—99% |

事件概率描述“结果发生的机会”，分析置信度描述“判断依据的稳固程度”。分别表达两者，例如：`【发生概率：较可能（55%—80%）；分析置信度：中】`。

### 置信度上限

- 只有 S4 线索时，信息可信度不得高于“未核实”，分析置信度只能为低；
- 存在未解决的关键来源冲突时，分析置信度不得高于中；
- 实体未完成消歧或当前状态超出时效窗口时，不得作为已确认事实进入执行摘要或行动建议。

## 5. 证据台账

为每个重要主张记录：

| 字段 | 要求 |
|---|---|
| Claim ID | 使用稳定编号，支持报告逐项映射 |
| 主张内容 | 用一句可证伪的话表达，不混合多个结论 |
| 内容类型 | 事实、推断、关键假设、情景预测或建议 |
| 主张级别 | A、B 或 C |
| 来源定位 | 标题、机构、直接链接、发布日期、更新日期、访问日期、页码或段落 |
| 来源层级 | S1—S4，并说明与主张的直接程度 |
| 独立性 | 独立、同源或未确认 |
| 证据关系 | 支持、部分支持、反驳或仅提供背景 |
| 时间与口径 | 统计期、事件日、地域、样本、币种、单位和定义 |
| 局限 | 无法访问、方法不明、利益冲突、样本限制或信息缺口 |
| 判断结果 | 已确认、初步确认、未核实或已反驳 |
| 分析置信度 | 高、中或低，并用一句话说明原因 |

证据台账默认作为内部工作记录。用户要求审计或深度模式确有需要时，输出精简版；不得输出内部逐步推理。

## 6. 冲突裁决

发现来源冲突时依次检查：

1. 是否在回答同一个问题；
2. 定义、地域、统计期、样本和币种是否一致；
3. 是否存在新旧版本、勘误、追溯修订或政策生效差异；
4. 谁最接近原始事件或具有最终裁决权；
5. 方法是否公开、可复核；
6. 是否存在商业、政治或组织利益；
7. 是否有第三个独立来源能够解释差异。

报告中保留仍然重要的冲突。只有存在明确方法依据时才选择某一数据；不得静默丢弃反证、机械平均或挑选更符合先入判断的数字。

## 7. 时效与实体核验

- 同时记录事件发生日、资料发布日期、更新日期、统计期和访问日期；
- 以用户规定的信息截止时间为硬边界，不引用其后的事实来解释此前判断；
- 对“最新”“当前”“现任”等主张优先打开官方当前页面，并检查页面更新时间；
- 对人物至少使用姓名之外的两个属性消歧；
- 对公司和机构优先核对法定名称、注册地、统一标识、母子关系和品牌名称；
- 对翻译名称保留原文名称，避免不同实体被合并；
- 无法完成消歧时明确写“身份未完全核实”，不得继续推断。
