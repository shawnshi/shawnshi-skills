# 报告规格与模板

根据任务模式选择最小充分结构。不要为了模板完整而填充无关章节。

## 1. 通用页眉

所有模式均标明：

- 报告主题；
- 决策问题；
- 模式；
- 信息截止时间及时区；
- 报告生成日期；
- 地域或司法辖区；
- 增量刷新时的基线版本或基线日期。

## 2. 快速核验

控制在 600—1000 字，使用以下结构：

1. **核验结论**：直接回答是、否、部分成立或无法核实；
2. **关键证据**：列出 2—4 项最直接证据并就近链接；
3. **实体或口径排除**：说明同名、时间、定义和地域核验；
4. **待核实项**：明确单一来源、失效页面和未解决矛盾；
5. **决策含义**：给出一个最低成本的下一步动作。

不要添加宏观框架、长期预测或泛化建议，除非它们直接回答决策问题。

## 3. 标准战略简报

### 执行摘要

控制在 300 字以内，包含：

- 3 项以内核心判断；
- 首要机会或风险；
- 一个最高优先级行动；
- 对关键判断的总体置信度说明。

### 范围与局限

简要说明决策问题、地域、时间、来源覆盖、重要假设和无法访问的材料。

### 关键判断

| 编号 | 判断与类型 | 核心证据 | 反证或局限 | 分析置信度 |
|---|---|---|---|---|
| K1 | `[事实/推断]` 一句话判断 | 就近链接主要来源 | 重要冲突或缺口 | 高/中/低及理由 |

表格只放可以准确映射的内容。复杂因果关系改用短段落解释，不把长文硬塞进表格。

### 决策相关分析

根据问题选择 2—4 个最有解释力的维度，例如：

- 政策与监管；
- 市场与经济；
- 技术与替代；
- 参与者、利益和能力；
- 供应链依赖与脆弱点；
- 事件时间线与因果链。

每个维度只写“证据—机制—对决策的影响”，避免重复事实基线。

### 替代解释与情报缺口

- 至少列出一个合理替代解释；
- 说明支持和削弱该解释的证据；
- 列出 3—5 个会显著改变判断的未知项；
- 给出需要继续监测的信号。

### 行动决策卡

每项建议包含：

| 字段 | 内容 |
|---|---|
| 行动 | 使用明确动词，能够直接分派 |
| 服务目标 | 说明支持哪个决策或降低什么风险 |
| 责任角色 | 指定角色，不臆测具体姓名 |
| 时间窗口 | 立即、30 天、季度内或与事件触发绑定 |
| 证据依据 | 映射关键判断或 Claim ID |
| 预期收益 | 说明业务价值，不编造财务数字 |
| 成本与难度 | 低/中/高并说明主要投入 |
| 前置依赖 | 数据、权限、合作方或政策条件 |
| 主要风险 | 执行副作用及缓解方式 |
| 启动/停止条件 | 给出监测阈值或判断信号 |

优先给出 2—3 项建议，至少包含一项低后悔行动。

### 来源说明

关键事实必须在正文就近链接。文末只补充：

- 主要来源类型和纳入排除原则；
- 无法访问或未采用的重要来源；
- 仍存在的来源冲突。

## 4. 深度研判

在标准简报基础上增加：

- 关键事件时间线；
- 参与者、利益、能力和约束；
- 两个以上替代假设；
- 基准、上行、下行或其他适当情景；
- 每个情景的触发条件、领先指标和失效条件；
- 关键依赖、二阶影响和反作用；
- 精简证据台账附录。

只在空间或时间关系确实影响判断时使用图表。图表中的分析结论同样必须有来源和置信度。

## 5. 增量刷新

不要重写完整旧报告。按以下结构输出：

1. **自基线以来发生了什么变化**；
2. **哪些原有判断保持不变**；
3. **哪些判断被上调、下调或推翻，以及原因**；
4. **新增或失效的证据链接**；
5. **行动建议是否需要调整**；
6. **下一次刷新触发条件**。

仅复核：当前状态、政策生效、人员任职、市场数据、事件进展、失效链接及此前低置信度主张。长期稳定的历史事实无需重复检索，除非出现反证。

## 6. 引用格式

- 网页：`[机构｜页面标题｜发布日期](直接链接)`；
- PDF：在链接后标注页码或章节；
- 数据库：标注表名、指标、统计期和访问日期；
- 无发布日期：写明“未标发布日期，访问于 YYYY-MM-DD”；
- 二手来源转引原始材料：优先链接原始材料；无法获得时明确写“经二手来源转引”；
- 付费墙或无法访问：不得依据摘要假装完成原文核验。

避免长篇引用原文。只摘取核验所需的最短片段，其余使用准确转述。

## 7. 交付前检查

- 执行摘要是否能独立回答决策问题；
- 每项关键事实是否有直接链接；
- A 级主张是否完成规定验证或明确降级；
- 是否把机构声明误写成客观事实；
- 是否披露重大冲突、反证和情报缺口；
- 是否区分事实、推断、假设、预测和建议；
- 概率和分析置信度是否分别表达；
- 建议是否具备责任角色、时间、依赖和触发条件；
- 是否删除无关个人信息和内部推理；
- 是否达到所选模式的篇幅和检索预算。
